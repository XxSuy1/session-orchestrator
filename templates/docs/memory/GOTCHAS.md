# GOTCHAS（踩过的坑；各线共用）

## 规则
- **只有总控写本文件。** 子会话把踩的坑写进回报的"值得记忆"一节，由总控验收时追加。
- 只在末尾追加。**唯一例外**：坑已经被自动防住或不再适用时，把它的"状态"一行改掉，其他内容一律不动。
- 编号 `G-<线名>-<三位序号>`；标签规则同 `DECISIONS.md`。
- 追加前先 Grep 同标签的条目。**同一个坑又踩到了、而它的"防护"还是"仅靠文档"** → 不新开条目，直接向用户提议把它做成自动防护（加进检查命令 / deny 规则 / hook）；改配置要用户同意，落地后把状态改成"已防护"。
- 已防护和不再适用的条目在合并到 main 时搬到 `ARCHIVE.md`（见 workflow.md §8）。

### G-<线名>-001 一句话现象

- 防护：（能自动防住就写怎么防：检查命令 / deny 规则 / hook；防不住写"仅靠文档"）
